# VisionCafe — Live Music Nights

A static cafe website featuring live music events, specialty coffee menus, table reservations, and a cozy Read & Sip section.

## Live Demo

[https://rnsingh123.github.io/Project0002/](https://rnsingh123.github.io/Project0002/)

## Stack

- HTML5, CSS3, Vanilla JS
- Google Fonts (Manrope)
- No frameworks, no build tools — pure static

## Project Structure

```
├── index.html       # Main page (entry point)
├── style.css        # All component styles
├── theme.css        # Design tokens (colors, spacing, shadows)
├── script.js        # Carousel + seat map + hamburger menu
├── assets/
│   └── favicon.svg  # SVG favicon
├── robots.txt
└── sitemap.xml
```

## Sections

- Hero with live event card
- Today's Specials
- Signature Drinks carousel
- Artist Line-Up
- Read & Sip
- Signature Menu
- Chef's & Barista's Picks
- Table Reservation with seat map
- Customer Reviews
- Map & Contact

## Deployment

### GitHub Pages

1. Go to repo **Settings → Pages**
2. Set source to `main` branch, `/ (root)`
3. Save — site will be live at `https://rnsingh123.github.io/Project0002/`

### Netlify / Vercel

Drop the repo folder or connect via GitHub — no build command needed, publish directory is `/` (root).

## Local Development

Just open `index.html` in a browser. No install or build step required.
